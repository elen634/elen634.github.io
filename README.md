# リビオタワー品川 ダッシュボード

港南3丁目の朝と帰りのための一枚ダッシュボード。
天気・品川駅まわりの運行状況・専用シャトルバスの発車案内をまとめて表示します。

ビルド不要・APIキー不要の静的サイトです。`index.html` を開くだけで動きます。

## 構成

```
index.html, assets/   ← このダッシュボード（リポジトリのルート）
progate/              ← 以前からある Progate の練習ページ
vercel.json           ← 検索避けヘッダのみ
```

ダッシュボードをルートに置いているので、GitHub Pages も Vercel も
追加設定なしでそのまま配信できます。

- GitHub Pages: https://elen634.github.io/ = ダッシュボード、`/progate/` = Progate
- Vercel: https://livio-dashboard.vercel.app = ダッシュボード

## Vercel で公開する

1. https://vercel.com/new を開く
2. `elen634/elen634.github.io` を **Import**
3. Project Name を `livio-dashboard` にして **Deploy**

**Root Directory と Output Directory は空のまま（既定のまま）にしてください。**
ダッシュボードがリポジトリのルートにあるので、変更すると逆に動きません。

## 設定

さわるのは **`assets/data.js`** だけです。

### 位置を正確にする

シェアサイクルのカード右上で、探す基準地点を切り替えられます。

- **リビオタワー品川** … 出かけるとき
- **品川駅港南口** … 帰ってくるとき
- **現在地** … 端末の位置情報

座標がずれていたら、その地点を選んだ状態で **［位置を直す］** を押して
緯度経度を貼り付けてください。端末に保存され、`data.js` の値より優先されます。
`places` の既定値はいずれも目安なので、未設定のあいだは注意書きが出ます。

天気はつねに `home`（リビオタワー品川）の地点を使います。基準地点を
品川駅に切り替えても天気は変わりません。

### 近隣バスの時刻表を入れる

`LOCAL_BUSES` の `table` に入れます。毎日同じダイヤならそのまま、
曜日で分かれるなら `weekday` / `saturday` / `holiday` に分けてください
（路線バスはたいてい後者です）。

```js
// 毎日同じ
table: { 7: [2, 18, 34, 50], 8: [4, 20, 36] }

// 曜日別
table: {
  weekday:  { 7: [2, 18, 34, 50], 8: [4, 20, 36] },
  saturday: { 7: [10, 40], 8: [10, 40] },
  holiday:  { 7: [15], 8: [15, 45] },
}
```

どのダイヤで表示中かはカード右上に出ます。`null` のあいだは公式時刻表への
リンクだけを表示します。

祝日は自動判定しません。`window.HOLIDAYS` に `'2026-10-12'` の形で足した日だけ
`holiday` ダイヤになり、それ以外の祝日は平日扱いです。

時刻表の入手先:

- 品99（港南中学校前 → 品川駅港南口）… [都バス運行情報サービス](https://tobus.jp/) / [NAVITIME](https://www.navitime.co.jp/bus/diagram/timelist?departure=00016828&arrival=00016924&line=00004136)
- ちぃばす 芝浦港南ルート（浜路橋 → 品川駅港南口）… [フジエクスプレス](https://www.fujiexpress.co.jp/chiibus/timetable/) / [東京都オープンデータカタログ（CSV）](https://catalog.data.metro.tokyo.lg.jp/dataset/t131032d0000000054)

### シャトルの曜日別ダイヤ

原本に曜日区分の記載がないため、いまは毎日同一ダイヤとして表示しています。
平日／土休日で分かれる場合は `directions[].table` を曜日ごとに分けてください。

### 自転車の判定基準

`bike` のしきい値（降水確率・雨量・風速）で変えられます。

## 注意

- 混雑リスクは、遅延の本数・通勤ピーク・雨から出した**推定**で、実測値ではありません。
- シャトルの時刻は配布資料の書き起こしです。ダイヤ改正時は `assets/data.js` を更新してください。
- おでかけ前に公式の運行情報もあわせてご確認ください。

## 検索避けについて

居住者専用のシャトル時刻表を含むため、検索エンジンに載らないようにしています。

- `index.html` の `<meta name="robots">`
- `vercel.json` の `X-Robots-Tag` ヘッダ

どちらも消せば通常どおりインデックスされます。なお、どちらの URL も
知っている人は誰でも開ける状態です（認証はかかっていません）。

## 運行情報を全路線ぶん取得する（ODPTキー）

キーなしの `api-public` でデータを返すのは**東京都交通局のみ**です
（2026-11 実測。JR東日本・京急・りんかい線・モノレールはいずれも 0 件）。
0 件は「平常運転」ではなく「取得できていない」ことを意味するため、
画面では「取得できず」と表示します。

JR と京急も出すには、無料の開発者登録でキーを取ります。

1. https://developer.odpt.org/ で登録（無料・事務局の確認に最大2営業日）
2. 発行された Consumer Key（アクセストークン）をコピー
3. ダッシュボードの「取得できず」の横にある **［キーを設定］** を押して貼り付ける
   （`?odptkey=コピーしたキー` を付けて開いても同じです）

キーはブラウザの localStorage に保存されます。
**このリポジトリは公開なので `data.js` には書かないでください。**

## ちぃばす時刻表（サーバー関数）

東京都オープンデータカタログはブラウザから直接叩くと CORS で止まるため、
`api/chiibus.js`（Vercel のサーバー関数）経由で取得します。

- `/api/chiibus` … 芝浦港南ルートの資源一覧
- `/api/chiibus?raw=1` … CSV の先頭を返す（形式確認用）

GitHub Pages ではサーバー関数が動かないため、この経路は Vercel 限定です。

## 品99 の土曜・休日ダイヤ

未取得です。tobus.jp の曜日指定の方法が分からず、平日ぶんだけ入れています。
土日は「時刻表を準備中」と表示され、平日の時刻は出ません
（土休日に平日のダイヤを見せると誤案内になるため、退避させていません）。

## 取得元の確認（サーバー関数）

`api/src.js` は、ブラウザからは CORS で届かない取得元をサーバー側で読み、
中身の先頭を返します。時刻表の形式を確かめて解析器を書くために使います。

```
/api/src?url=https://tobus.jp/...&lines=80
```

取得先はバス事業者と東京都のサイトに限定しています（任意のURLは踏みません）。

## 接続チェック

外部データに届いているかは `/check.html` で確認できます。
事業者ごとに OK / NG と、最寄りポートまでの直線距離が出ます。

## iPhone のホーム画面に置く

Safari で開く → 共有ボタン → 「ホーム画面に追加」。
アドレスバーの無い全画面で起動します（`manifest.webmanifest` と

## LUUP について

LUUP はポートの空き状況を公開API（GBFS等）で提供していません。
NAVITIME や駅すぱあとは提携によるデータ連携で、一般に開かれた口ではないため、
このダッシュボードからは取得できません。アプリを開くボタンのみ置いています。

iPhone アプリの中のデータを Web ページから読むことはできません（iOS が
アプリ間を隔離しているため）。LUUP アプリの非公開 API を叩く方法は、
CORS で塞がれていること、公開URLに認証トークンを置くことになること、
利用規約に抵触することから採りません。

`check.html` で ODPT の GBFS に LUUP が居るかを総当たりで確認できます。
提供が始まったらそこで分かります。

## 徒歩の所要時間について

港南と天王洲のあいだは運河で隔てられており、直線距離と実際に歩く距離が
大きく食い違います（直線155mでも橋を回ると700m超になることがあります）。
そのため直線距離から分数を作らず、歩行者経路検索に成功したときだけ
「徒歩◯分」を出し、失敗したときは直線距離だけを表示します。
